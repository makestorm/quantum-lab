1. 研究问题与实验目的

原始问题

计算 Ωx=2、Ωz=1 的自旋二能级系统，画出演化曲线，并解释为什么跃迁概率达不到 1。

实验目的

  • 用户原始问题：计算 Ωx=2、Ωz=1 的自旋二能级系统，画出演化曲线，并解释为什么跃迁概率达不到 1。
  • 实验目的：用本地谱分解求解 自旋 1/2 二能级系统，并按固定检查表验证数值与解析参照的一致性。

2. 模型公式与假设

模型：自旋 1/2 二能级系统（spin_half）

基矢：|↑⟩=(1,0)ᵀ、|↓⟩=(0,1)ᵀ（σz 本征态）

哈密顿量：H = (1/2)(Ωx σx + Ωy σy + Ωz σz)

公式

  • H = (1/2)(Ωx σx + Ωy σy + Ωz σz)，ħ = 1
  • |Ω| = √(Ωx² + Ωy² + Ωz²)，本征能量 E± = ±|Ω|/2
  • 演化算符 U(t) = V exp(−iΛ(t−t₀)) V†（H = V Λ V†）
  • Bloch 进动：n(t) = n̂ cos(|Ω|t) + (Ω̂×n̂) sin(|Ω|t) + Ω̂(Ω̂·n̂)(1−cos(|Ω|t))
  • 从 |↑⟩ 出发：P↓(t) = (Ω⊥²/|Ω|²)·sin²(|Ω|t/2)，Ω⊥² = Ωx² + Ωy²

假设与约定

  • 理想二能级自旋，ħ = 1，能量与角频率同量纲，时间以 Ω⁻¹ 为单位；
  • 哈密顿量厄米且在本实验时间窗内不显含时间（Ω 恒定）；
  • 演化严格幺正：无退相干、无耗散、无测量反作用；
  • 解析参照为 Bloch 进动闭式解，仅用于交叉校验数值演化。

单位约定：ħ = 1.0，ħ=1，Ω/ω/Δ/λ 与角频率同量纲

7. 结果解释与适用限制

发生了什么

  • 等效拉比频率 |Ω|=√(Ωx²+Ωy²+Ωz²)=2.23607，能级 E±=±1.11803，完整进动周期 2π/|Ω|=2.80993。
  • 初态 |↑⟩（σz 本征态）；时间窗 [0, 2.80993]（401 点），相位以 t_start 为零点。
  • P↓ 数值峰值 0.8，解析峰值 0.8；从 |↑⟩ 出发的理论上限 Ω⊥²/|Ω|²=0.8。
  • Bloch 解析解最大绝对偏差 1.110e-15；能量期望 ⟨H⟩=0.5 相对漂移 5.55e-16。

为什么

  • 等效拉比频率 |Ω| = 2.236068，Bloch 矢量以该角频率绕 Ω 方向进动，故时间振荡的角频率是 |Ω| 而不是 Ω⊥。
  • Ωz = 1 使本征态偏离 σz 基，最大跃迁概率被限制为 Ω⊥²/|Ω|² = 0.8。
  • 本实验含解析参照「Bloch 进动解析解」，对比指标见验证表。

限制与未验证部分

  • 统一采用 ħ=1 的无量纲约定：能量与角频率同单位、时间以 Ω⁻¹ 或 ω⁻¹ 度量。
  • 求解器为厄米矩阵谱分解 np.linalg.eigh（U(t)=V e^{-iΛ(t-t_start)} V†）；误差指标只衡量数值一致性，不替代物理建模假设。
  • 仅对 Ωx=2.0、Ωy=0.0、Ωz=1.0、初态 kind='up'、t∈[0.0, 2.8099258924162904] 成立；未验证含时驱动、退相干与噪声。
  • 未涵盖：有限温度、开放量子系统（Lindblad/退相干）、多体关联、显含时哈密顿量与实验噪声。
  • 结论仅对本次参数（Ωx（横向驱动）=2、Ωy（横向驱动）=0、Ωz（纵向/失谐）=1）与给定初态/时间窗成立。
